Little Lemon Web Application — API Endpoints

Base URL: http://127.0.0.1:8000/

1. Restaurant home: /restaurant/
2. Menu: /restaurant/menu/
3. Booking API: /restaurant/booking/
4. Booking tables: /restaurant/booking/tables/
5. Authentication API: /auth/
6. Authentication users: /auth/users/
7. Admin panel: /admin/

Framework: Django and Django REST Framework.

Run locally:
python manage.py runserver
